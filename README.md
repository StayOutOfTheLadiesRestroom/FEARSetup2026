# FEARSetup2026

An automated installer designed to simplify setting up **F.E.A.R. (2005)** with community patches, graphical enhancements, gameplay modifications, and optional quality-of-life improvements.

## Features

- Echo Patch installation
- Sikkmod installation
- Mutilation installation with three selectable variants:
  - Base
  - Plus
  - Payneful
- True F.E.A.R. installation
- Optional Disable Cutscene Letterboxing setting
- Optional Infinite Flashlight setting
- Custom Weapon Capacity configuration
- Automatic Steam game detection
- Manual game directory selection
- Automatic installation backups and restoration support
- Installation progress reporting
- Single-file executable
- Windows administrator privilege support

## Requirements

- F.E.A.R. (2005), Steam version recommended
- Windows

## Included Components

- Echo Patch
- Sikkmod
- Mutilation (Base / Plus / Payneful)
- True F.E.A.R.

## Important Notes

- Mutilation Plus conflicts with Echo Patch's Custom Weapon Capacity option. Avoid enabling both together.
- The installer creates backups of affected game files to support restoration.
